# infiniscope

Infiniscope is a custom 12-bit oscilloscope made with the RP2350, and the AD9238BSTRL ADC. It is made on a 4-layer stackup with sig-gnd-pwr-sig as the stackup. it has a BNC connector which can be used to attach a probe and measure signals. There are 3 options that are selectable, time divison, gain and ac/dc coupling, which helps in measuring different kinds of signals. the basic test firmware for this O-scope can be found [here](https://github.com/Keyaan-07/scope-fw) written by yours truly(Keyaan). The firmware is custom written in C and can be modified easily according to user needs. There is an optional display for the display, but it hasn't been showin in this instance.
